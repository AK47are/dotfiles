Learning records: decision-grade docs in teaching. Capture non-obvious lessons, key insights, stated prior knowledge. Guide future sessions; inform zone of proximal development.

## Write when (any)
- User showed genuine understanding of non-trivial thing: evidence they can USE it correctly, not just exposure. Sets new floor for teaching
- User disclosed prior knowledge (「I already know X」) ⇒ record so future sessions don't re-teach; record claimed depth too
- Misconception corrected: believed wrong, now sees why. High-value: predicts future stumbling blocks on related topics
- Mission shifted with learning: user discovered caring about something different than assumed. Cross-link `MISSION.md`, update it

## Exclude
- Mere coverage. Coverage not learning; wait for evidence
- Already tersely in `GLOSSARY.md` as term definition. Don't duplicate
- Session logs. Learning records not a journal; decision-grade insights only

## Template
```md
## {Short title}

{1-3 sentences: what was learned (or what prior knowledge was established), and why it matters for future sessions.}
```
Whole format. Single paragraph OK. Value: recording THAT this is now known and WHY it changes what to teach next: not section-filling.

### Optional sections
Only when genuine value; most records skip:
- Status frontmatter (`active | superseded by LR-NNNN`) when earlier understanding wrong, replaced
- Evidence: how understanding was shown (question answered, exercise completed, prior experience cited), when claim may be revisited
- Implications: what this unlocks or rules out, when non-obvious

## Supersession
Later record contradicts earlier (understanding deepened/corrected) ⇒ mark old `Status: superseded by LR-NNNN`, don't delete. Evolution history: useful signal itself.
