## 工具调用常见错误及原因

### 1. 使用了不存在的参数

- **错误示例**：在 Bash 工具调用中添加 `_raw` 参数
- **原因**：工具的参数列表是固定的，添加未定义的参数会导致验证失败
- **正确做法**：只使用工具定义中明确列出的参数

### 2. 直接编辑文件而未先读取

- **错误示例**：调用 Write 工具覆盖文件，但之前没有用 Read 读取
- **原因**：Write 工具要求必须先读取文件，以防止意外覆盖
- **正确做法**：任何修改操作（Write/Edit）前，先用 Read 读取目标文件

### 3. Edit 操作的 old_string 匹配失败

- **错误示例**：old_string 与文件实际内容不完全匹配（包括空格、换行符）
- **原因**：Edit 要求精确匹配，微小差异会导致失败
- **正确做法**：从 Read 输出中直接复制要替换的字符串，确保逐字符一致

### 4. 在 Windows 上错误使用 Bash 工具

- **错误示例**：在 Windows 系统上使用 Bash 工具执行命令
- **原因**：全局 CLAUDE.md 规定优先使用 PowerShell 工具
- **正确做法**：Windows 环境下默认使用 PowerShell 工具，除非有特殊原因必须用 Bash

### 5. 忘记必填参数

- **错误示例**：调用 Edit 时省略 `file_path`、`old_string` 或 `new_string`
- **原因**：未仔细阅读工具的参数要求
- **正确做法**：调用前确认所有 required 参数都已提供

### 6. 并行调用中依赖顺序

- **错误示例**：多个 Edit 调用之间存在依赖关系，但未正确处理顺序
- **原因**：前一个 Edit 的结果会影响后一个的 old_string 匹配
- **正确做法**：有依赖关系的操作应串行执行，确保前一步完成后再进行下一步
