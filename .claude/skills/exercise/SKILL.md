# 练习技能

核心原则：**不只看文字，必须动手写代码。** 无论概念多简单，都应产出有明确验证标准的结构化练习。

## 前置研究

生成练习前必须完成：

1. 搜索用户 Obsidian 笔记（`~/obsidian/notes`），查找该主题的现有笔记
2. 阅读相关笔记，了解用户当前深度——不练习已掌握的内容
3. 在练习 README 中引用笔记，连接新旧知识
4. 根据笔记深度设定难度：笔记匮乏→基础练习，笔记详细→进阶练习
5. 指出笔记中的具体遗漏点作为练习目标

## 输出结构

练习文件放在 `.claude/exercises/<主题slug>/`，主题 slug 使用 kebab-case（如 `hashmap-internals`、`thread-pool`、`redis-cache-strategy`）。

```
.claude/exercises/<主题slug>/
├── README.md              # 练习说明、学习目标、提示
├── <测试文件>              # 测试代码——先于实现代码提供
├── <骨架文件>              # 带 TODO 标记的骨架代码
└── solution/
    ├── README.md          # 解答说明——解释为什么这样做
    └── <解答文件>           # 完整的参考实现
```

多任务渐进式练习：

```
.claude/exercises/<主题slug>/
├── README.md              # 总体说明与学习路径
├── task-01-<子主题>/
│   ├── README.md
│   ├── <测试文件>
│   ├── <骨架文件>
│   └── solution/
│       └── ...
├── task-02-<子主题>/
│   └── ...
```

## 练习模板

每个练习的 README.md 按以下结构编写：

```markdown
# [概念名称]练习

> 对应笔记：[笔记文件名](~/obsidian/notes/路径) — 笔记已有的内容和遗漏点

## 学习目标
- [具体、可验证的目标——不是「理解 X」而是「实现能做 Y 的 X」]
- [每个目标应可测试]

## 前置知识
- [来自用户笔记的概念，建议先复习]

## 验证方式

实现是否正确，通过以下测试验证：

[在此直接列出测试代码或描述测试用例]
- 测试 1：[输入] → [预期输出]
- 测试 2：[输入] → [预期输出]

运行命令：`[编译运行命令]`
预期：所有测试通过

## 任务说明
[清晰描述要做什么，包括输入输出、行为约束]

## 要求
- [ ] [具体要求]
- [ ] [边界条件要求]

## 起步代码
[骨架文件路径——哪些已提供、哪些需用户编写]
```

## 解答生成与自审查

生成参考解答时必须执行自审查：

1. 先编写解答代码和解答说明
2. **启动 agent 审查解答**：用独立 agent 验证解答的正确性、完整性和可理解性
3. 修复审查发现的问题后再保存到 `solution/` 目录
4. 解答说明（solution/README.md）必须解释**为什么**这样写，而不是只列出代码

## 引导原则

用户练习过程中遇到问题时，**不直接给出答案**，而是引导思考：

- **编译错误**：分析错误信息，指出类型/语法问题出在哪一行，让用户自己修正
- **逻辑错误**：描述预期行为与实际行为的差异，问「当输入是 X 时，你的代码会输出什么？」
- **不会做**：拆解问题，先问用户对哪个子问题有思路，逐步引导
- **请求直接看答案**：先给出提示，鼓励再试一次；用户坚持时再提供解答

## 练习后流程

1. 用户告知完成练习
2. 读取用户的实现文件
3. 从以下维度评估：
   - 正确性：是否满足所有要求
   - 设计：是否有更好的写法
   - 边界条件：是否处理了 edge case
   - 笔记关联：是否填补了笔记中的知识缺口
4. 给出针对性反馈——做得好的点、可改进的点
5. 根据表现建议下一个练习主题

## 目录索引维护

`.claude/exercises/` 根目录需维护一个 README.md 作为练习索引：

```markdown
# 练习目录

| 主题 | 日期 | 类型 | 概念 | 状态 |
|------|------|------|------|------|
| hashmap-internals | 2026-05-09 | TODO填空 | HashMap 底层结构 | 已完成 |
| thread-pool | 2026-05-10 | 完整实现 | 线程池参数调优 | 待练习 |
```

每次创建新练习后更新此索引。
